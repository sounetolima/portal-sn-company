# Portal Executivo SN Company

Dashboard executivo para CEO Susana Nóbrega — The Hair Bar + SN Table Decor

## Deploy Netlify

1. **Conectar repositório Git**
   - GitHub/GitLab com este projeto
   - Netlify detecta automaticamente `netlify.toml`

2. **Deploy automático**
   - Cada `git push` = novo deploy
   - Atualizações refletem em minutos

3. **Atualizações diárias**
   - Edit `index.html` ou `data.json`
   - Git commit + push
   - Netlify faz deploy automaticamente

## Arquivos

- `index.html` - Portal completo (auto-contido)
- `data.json` - Dados financeiros (separado)
- `netlify.toml` - Configuração Netlify

## URL

`https://portal-sn-company.netlify.app` (após conectar)
